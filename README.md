# Clinic OPD Management System

MERN-based clinic management system for managing:

- Patient OPD records
- Medicine inventory
- Stock bills
- Expiry tracking
- Dashboard analytics

## Tech Stack

- React
- Vite
- Tailwind CSS
- Node.js
- Express.js
- MongoDB
